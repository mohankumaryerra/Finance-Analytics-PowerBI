# Finance Analytics Dashboard using Power BI

## Overview
This project is an interactive Finance Analytics Dashboard developed using Power BI. The dashboard analyzes banking transaction data and provides insights into customer behavior, transaction trends, fees, and overall financial performance.

## Key Features

* Data Cleaning and Transformation using Power Query
* Data Modeling and Relationship Building
* DAX Measures and KPI Development
* Year-over-Year (YoY) Analysis
* Customer Segmentation Analysis
* Transaction Type Analysis
* Interactive Filters and Slicers
* Financial Performance Tracking

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Key KPIs

* Total Amount
* Total Transactions
* Average Transaction Value
* Total Fees
* YoY Growth Analysis
